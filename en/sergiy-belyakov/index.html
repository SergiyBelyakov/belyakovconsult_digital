My approach

How I work

I came to data work through real management problems. It started with maps of healthcare facilities and access to services, then moved into BI, reform monitoring, social protection and large information systems. The same issue kept appearing: there can be a lot of data and still no coherent picture for a decision.

That is why I do not start with a dashboard or a technology. I start with the decision that needs to be made, the sources that already exist, the contradictions between them and what can actually be verified. From there it becomes clear whether the task needs BI, data architecture, data quality rules, Data Governance or geospatial analysis.
