ПУБЛІКАЦІЯ BELYAKOV CONSULT У MAIN

1. Розпакуйте весь архів у будь-яку папку на macOS.
2. Відкрийте Terminal у папці з deploy_main.sh.
3. Виконайте: bash deploy_main.sh

Скрипт клонує поточний main, видаляє з робочого дерева застарілі файли,
копіює весь новий сайт із папки site, створює один коміт і пушить у main.
Історія Git зберігається. Force push не застосовується.

Вимоги: Git, rsync, доступ на запис у зазначений репозиторій.
Для авторизації GitHub через GitHub CLI, якщо потрібно:
  gh auth login
  gh auth setup-git

URL репозиторію:
https://github.com/SergiyBelyakov/belyakovconsult_digital

Публікація в GitHub не обов'язково означає автоматичну публікацію домену.
Це залежить від налаштувань Cloudflare Pages / GitHub Pages.
